A/B 实验显著性教程

从"点击率是什么"开始，一步步搭出 CTR → SE → Z → P 值 → 置信区间的完整推理链条。每一节都可以动手试。

目标读者：完全没学过统计的产品/研发/数据同学
第 0 章 · 直觉

你首先要学会问一个问题

这一章不讲公式，只讲一种思考习惯。后面所有的数学都是为它服务的。

假设你上线了一个新的广告样式（叫 B 版），旧样式叫 A 版。运营告诉你：

A 版：8,000 次曝光，2,000 次点击 B 版：9,000 次曝光，2,400 次点击

B 版看起来点击数更多。你敢直接下结论"B 更好，全量上线"吗？

?
请自己想 10 秒：你会有哪些顾虑？B 真的更好，还是有别的解释？

更准确地说，我们真正要回答的是两个问题：在同样分流和同一指标口径下，B 的真实 CTR 是否高于 A？如果高，高出的幅度是否足以支撑上线？

你至少会想到两个问题：

  1. 曝光量不一样。 B 曝光更多，点击自然可能更多，直接比点击数不公平。
  2. 抽样有随机性。 即便两版本效果一样，几千次曝光也可能因为运气产生看起来不小的点击数差异。

整个统计推断，本质上就是在系统性地回答这两个问题：

  • 第一个问题引出 点击率 CTR（第 1 章）
  • 第二个问题引出 SE / Z / P 值 / 置信区间（第 3~7 章）
i
整份教程用同一个案例贯穿：A=8000/2000，B=9000/2400。你会看到每一个概念是怎么"顺着这个案例"被发明出来的。
小测验 0.1：看到 B 点击数比 A 多 400 次，为什么还不能直接上线？
第 1 章 · 概念

点击率 CTR：把不同曝光量拉到同一把尺子

目标：解决"曝光量不同不能直接比"的问题。

1.1 为什么要有 CTR

如果两组曝光量一样，比点击数就够了。但只要曝光不同，就必须先"归一化"。最自然的归一化方式是：

点击率 CTR = 点击次数 / 曝光次数 = click / send

它的含义是：平均每一次曝光，有多大概率带来点击。这是一个 0 到 1 之间的比例，用百分号表示更直观。

A 版 CTR
25.00%
= 2,000 / 8,000
B 版 CTR
26.67%
= 2,400 / 9,000

换成 CTR 后，B 只比 A 高了 1.67 个百分点。直接看"多了 400 次点击"其实高估了差距。

1.2 亲手玩一下 CTR

下面这个小实验只讲一件事：拖动滑块，看 CTR 是怎么算出来的。绿色方块代表被点击的曝光。

1.3 两种"提升"，别搞混

产品同学口中的"提升"其实有两种表达方式：

叫法公式本例数值什么时候用
绝对提升（百分点 p.p.） p_B − p_A 26.67% − 25.00% = +1.67 p.p. 做减法，直观看差距
相对提升 (p_B − p_A) / p_A (26.67% − 25.00%) / 25.00% = 0.0167 / 0.25 = +6.7% 汇报"涨了百分之多少"
!
常见误读：新闻里说"点击率涨了 6.7%"，很多人以为 CTR 从 25% 涨到了 31.7%。实际上只涨了 1.67 p.p.。分清"百分点"和"百分比"是数据素养的第一课。
小测验 1.1：CTR 从 5% 提升到 6%，是几个百分点，涨了百分之几？
第 2 章 · 直觉

CTR 也是随机的：为什么我们需要统计

目标：理解抽样波动，明白"看到 26.67% 不能马上相信"。

2.1 一次曝光就是一次抛硬币

每一次曝光，只有两种结果：点击（1）或不点击（0）。这就是一次伯努利试验，跟抛硬币是一回事，只不过硬币正面朝上概率不一定是 50%。

Y ∈ {0, 1}，P(Y=1) = p，P(Y=0) = 1 − p

如果真实点击概率是 p = 25%，那么每次曝光独立地以 25% 概率变成 1。你观测到的 CTR 只是 n 次结果的平均值：

观测 CTR p_hat = (Y₁ + Y₂ + ... + Yₙ) / n

p_hat（读 "p hat"）是"从数据估计出来的 p"，不是真实的 p。每次做实验，p_hat 都会不一样，即使真实的 p 没变。

i
这里的“独立”是一个建模假设：真实业务里如果同一用户反复曝光、流量分层或存在时间波动，就要在实验设计和分析里额外处理。这个教程先用最基础的独立伯努利模型搭主线。

2.3 这个分布是什么？

i
三个符号先对齐：K 是 500 次曝光里实际点击了多少次；p_hat = K / 500，是这一次实验看到的 CTR；SE 是如果重复做实验，p_hat 典型会抖多宽。

严格来说，"500 次曝光里的点击数 K"服从二项分布：

K ~ Binomial(n=500, p=0.25) 观测 CTR = K / 500，是离散分布

但当样本量够大时（经验判据 np ≥ 10 且 n(1−p) ≥ 10，本例 125 和 375 都远大于 10），根据中心极限定理，它非常接近正态分布：

观测 CTR ≈ Normal(mean = p, sd = √(p(1−p)/n)) = Normal(mean = 0.25, sd = 0.0194)

Lab 2 图里的橙色曲线画的就是这个正态。你抽的次数越多，蓝色直方图越贴橙色曲线。这个"二项 → 正态"正是后面第 5 章我们敢用 Z 检验的根本原因。

!
关键洞察：如果 CTR 天然就会抖动几个百分点，那么看到 B 比 A 高 1.67 p.p. 时你不能马上下结论——这可能只是抖动。接下来我们要给这个"抖动"一个数字：标准误 SE。
第 2.5 章 · 前提

先确认实验可信，再计算显著性

目标：统计公式只能回答“随机波动够不够解释差异”，不能替你修复错误分流、脏数据或实验污染。

从第 3 章开始，我们会假设 A/B 数据已经可信。但在真实工作里，先做一个健康检查更重要。否则你算出来的 P 值很漂亮，也可能只是把脏数据算得很精确。

2.5.1 五个必须先问的问题

检查项要确认什么为什么影响显著性
随机分流 A、B 用户是否真的是随机进入？ 如果 B 组天然更活跃，CTR 更高可能来自人群差异，不是版本效果。
实验单位 按用户分流，还是按曝光/请求分流？同一用户会不会同时看到 A 和 B？ 用户被两个版本交叉影响时，两组不再独立，SE 会被低估。
SRM 样本比例是否符合预设，比如 50/50 实验是否接近 50/50？ Sample Ratio Mismatch 常常意味着分流、过滤或埋点出了问题。
埋点一致 A、B 的曝光和点击口径是否完全一致？ 如果新版漏记曝光或多记点击，统计检验只会放大口径错误。
时间与外部事件 A、B 是否覆盖同一时间段，是否遇到活动、节假日、故障？ 时间因素会让“版本差异”和“环境变化”混在一起。

2.5.2 一个最小 SRM 例子

假设你计划 A/B 各 50% 流量，总曝光 100,000。正常情况下，A、B 应该都在 50,000 附近小幅波动。如果实际是：

A：60,000 次曝光 B：40,000 次曝光

这时先不要急着算 CTR 的 P 值。更优先的问题是：为什么分流比例偏这么多？可能是过滤规则只影响某个版本、某些端没有进实验、或者埋点上报有缺口。

!
顺序很重要：先检查实验是否可信，再解释效果是否显著。显著性检验解决的是随机误差，不解决系统性偏差。
小测验 2.5：如果 50/50 实验最后流量变成 A=60%、B=40%，第一反应应该是什么？
第 3 章 · 公式

标准误 SE：抖动到底有多大

目标：给出第一个正式公式，并推导它从哪里来。

3.1 从单次曝光的方差开始

方差衡量"结果有多不确定"。伯努利分布的方差有一个漂亮的公式：

Var(Y) = p · (1 − p)

直觉：p 越接近 0.5，结果最难猜（方差最大）；p 越接近 0 或 1，结果越确定（方差越小）。

3.2 平均后方差怎么变

观测 CTR 是 n 次独立试验的平均：p_hat = ΣYᵢ / n。概率论有一条基本规则：n 个独立同分布随机变量求平均后，方差缩小 n 倍。

Var(p_hat) = Var(Y) / n = p(1 − p) / n

方差单位是"平方"，量纲不好读。开个方就得到"平均值的典型抖动幅度"，这就是标准误 SE：

SE(p_hat) = √( p(1 − p) / n )
i
怎么记？SE ∝ 1/√n。样本量翻 4 倍，SE 缩小一半。想让 SE 减半，样本量要涨到 4 倍。

3.3 现实里 p 是未知的：从样本估方差

上面推导的 Var(p_hat) = p(1−p)/n 里出现了 真实的 p，但真实做实验时你根本不知道 p——你只有一堆 0/1 数据。这一步就是从"理论"过渡到"实践"的关键。

方法 1：直接用样本估计 p̂ 代替 p（比例的常用做法）

因为大数定律保证 p_hat → p，所以用它去替换公式里的 p 是合理的。这就得到 样本方差 / 样本标准误：

Var_hat(p_hat) = p_hat(1 − p_hat) / n SE_hat(p_hat) = √( p_hat(1 − p_hat) / n )

代入 A 版观测数据 p_hat = 0.25，n = 8000：

SE_hat = √(0.25 × 0.75 / 8000) ≈ 0.00484 ≈ 0.48%

这个数值和前面“用 p≈0.25 推导”的演示结果相同，是因为本例的样本 p_hat 正好就是 0.25。真实 p 永远不可见；实践中只能用 p_hat 去估计它，大样本下这个估计通常足够接近。

方法 2：直接从 0/1 数据算样本方差（通用做法）

方法 1 是"比例"这个特殊场景的偷懒公式。如果你手上只是一列 0/1 数据（点击=1，不点=0），完全可以像对一般数据一样，用样本方差公式：

样本均值 p_hat = (1/n) Σ Yᵢ 样本方差 s² = (1/(n−1)) Σ (Yᵢ − p_hat)² 均值的 SE SE_hat(p_hat) = s / √n

对 0/1 数据展开 s²，可以化简为：

s² = n/(n−1) · p_hat(1 − p_hat)

所以两种方法几乎相等，只差一个 n/(n−1) 的贝塞尔修正因子（Bessel's correction），当 n 很大时可以忽略。

i
为什么分母是 n−1 不是 n？关键在于：样本均值 p_hat 本身就是从这组数据算出来的，它永远处在数据的正中央。用一个"跟着数据跑"的中心去量偏离，得到的偏差平方和永远比用真值 p 更小。
小例子：真实 p = 0.5，抽到 Y = [1, 1, 1, 0]，此时 p_hat = 0.75。
用真值 p = 0.5 算：Σ(Yᵢ − 0.5)² = 1.00
用样本 p_hat = 0.75 算：Σ(Yᵢ − 0.75)² = 0.75（少了 25%）
这个系统性低估的幅度，数学上正好是 (n−1)/n。所以用 n−1 做分母就能刚好补回来，让 s² 成为 Var(Y) 的无偏估计——这叫 Bessel 修正。当 n 很大时 n/(n−1) ≈ 1，这个修正可以忽略。

三层公式一览

层次公式什么时候用
理论方差（用真 p） p(1−p) / n 推导、教学、上帝视角
样本方差（用 p_hat 代入） p_hat(1−p_hat) / n 实际做检验、构造 SE
通用样本方差（Bessel 修正） s² / n，其中 s² = Σ(Yᵢ−p_hat)² / (n−1) 不假设伯努利、通用做法

3.4 标准差 SD vs 标准误 SE：最容易混的一对

这两个词长得像，很多人以为是同一个东西。它们确实有关系，但描述的是完全不同的对象。一句话记住：

≠
SD 描述"数据本身"有多散；SE 描述"用数据算出来的统计量"有多不稳定。
标准差 SD标准误 SE
描述的对象 单次观测 Y 基于 n 次观测算出的统计量（如样本均值 p_hat）
回答的问题 一个用户点不点击，结果有多不确定？ 反复做 8000 次曝光的实验，得到的 CTR 会抖动多少？
公式（伯努利） SD(Y) = √(p(1−p)) SE(p_hat) = √(p(1−p)/n) = SD / √n
本例（p=0.25, n=8000） √(0.25×0.75) ≈ 0.433 0.433 / √8000 ≈ 0.0048 = 0.48%
n 增大时 不变（数据本身没变） 缩小 1/√n（估计越来越准）

核心关系式：

SE = SD / √n

换句话说：SE 就是"均值这个统计量的 SD"。所以有些教材直接说"均值的标准差"，指的就是 SE。

"均值的 SD" 是什么意思？做个思维体操

SD 本来是描述"一列数字"的散布程度。SE 说"均值也有 SD"，那这个 SD 是谁的 SD？

想象你把整个 A/B 实验从头再做一遍。抽样有随机性，你会得到一个不一样的 p_hat。做第三遍、第四遍，每次得到的 p_hat 都不一样：

第 1 次实验：p_hat = 0.2510 第 2 次实验：p_hat = 0.2483 第 3 次实验：p_hat = 0.2524 ... 第 1000 次： p_hat = 0.2511

这 1000 个 p_hat 本身就是一列数字。这列数字有它自己的平均值（≈ 真实 p）和标准差——那个标准差就是 SE。

SD(Y)SE(p_hat)
观察对象 单次曝光的结果 Y ∈ {0,1} 做完一次完整实验后得到的 p_hat
怎么才能"看见"它 把很多次曝光记下来，算标准差 把整个实验重复很多次，看每次 p_hat，算标准差
本例数值（p=0.25, n=500） ≈ 0.433 ≈ 0.0194 = 0.433 / √500
i
Lab 2 就是在演示这件事。你每点一次"再抽 500 次曝光"，就相当于把整个实验重做一次，得到一个 p_hat（一根柱子的位置）。点上百次之后，那些 p_hat 组成的直方图有一个宽度——那个宽度就是 SE。理论上 68% 的柱子落在 25% ± 1.94% 之间，你可以对着 Lab 2 数一下是不是。
!
汇报陷阱：论文/报告里看到 "mean ± X"，务必看清楚 X 是 SD 还是 SE。SD 反映数据分布宽度，SE 反映"这个均值估得准不准"，两者可能差一个 √n 倍。

3.5 代入本例

以 A 版为例，p ≈ 0.25，n = 8000：

SE(p_hat_A) = √(0.25 × 0.75 / 8000) = √(0.0000234) ≈ 0.00484 ≈ 0.48 个百分点

意思是：即使真实 CTR 就是 25%，你反复做实验，观测到的 CTR 会在 25% 上下典型地抖动约 0.5 个百分点。

3.7 进阶备注：理论 SE vs 样本 SE

严格讲，"标准误"其实分两种。教材里通常会明确区分，但本教程一直用的是它们混着看的简写版。

理论 SE样本 SE（记作 SE_hat）
用什么算 真实的 p（上帝视角） 数据估出的 p_hat
比例（伯努利） √(p(1−p)/n) √(p_hat(1−p_hat)/n)
正态均值 σ / √n（σ 已知） s / √n（用样本标准差 s）
典型使用 推导标准误、构造理想化的 Z 统计量 连续均值指标里 σ 未知时，常引出 t 检验
i
为什么本教程没细分？因为在比例检验里，p_hat 是 p 的一致估计，两个公式数值几乎一样（本例 SE 都是 0.48%），实践中不用刻意区分。
但请记住这一层：比例检验里虽然 SE 也来自样本估计，但大样本下通常仍用正态近似；连续均值指标在 σ 未知、需要用 s 估计时，才更自然地引出 t 检验。t 分布就是为补偿这份多出来的不确定性而设计的。
第 4 章 · 公式

两组差异的 SE：把两把尺子合成一把

目标：我们关心的是 p_B − p_A 的抖动，不是单组的抖动。

4.1 独立随机变量差的方差

概率论有一条基本规则：两个独立随机变量的差，方差等于方差相加（不是相减！）：

Var(X − Y) = Var(X) + Var(Y) （当 X、Y 独立时）

A、B 两组用户不重叠，可以视为独立。所以：

Var(p_hat_B − p_hat_A) = p_A(1−p_A)/n_A + p_B(1−p_B)/n_B SE_unpooled = √( p_A(1−p_A)/n_A + p_B(1−p_B)/n_B )

这叫 unpooled SE（不合并 SE），常用于构造置信区间。

这里公式里的 p_A、p_B 是理论上的真实点击率。真实实验里看不到它们，所以实际计算会用样本里的 p_hat_A、p_hat_B 代入估计。

4.2 假设"两组一样"时的 SE

做显著性检验时，我们要回答的是"假如两组真实 CTR 相等，看到 1.67 p.p. 差异有多罕见"。这个假设叫零假设 H₀。

既然假设两组 p 相等，就把两组数据合起来估一个共同的 p：

p_hat_pool = (x_A + x_B) / (n_A + n_B) = (2000 + 2400) / (8000 + 9000) = 4400 / 17000 ≈ 0.2588

用这个共同 p 去算 SE，叫 pooled SE：

SE_pool = √( p_hat_pool(1−p_hat_pool) · (1/n_A + 1/n_B) ) = √( 0.2588 × 0.7412 × (1/8000 + 1/9000) ) ≈ 0.00672 ≈ 0.67 个百分点
i
为什么要有两种 SE？
因为它们回答的是两个不同问题。检验问的是“如果 A、B 真的一样，看到现在这个差异有多罕见？”；估计问的是“真实差异大概是多少？”这两个问题的前提不同，所以 SE 的估法也不同。
使用场景正在回答的问题核心假设该用哪个 SE
Z 检验 如果两组真实 CTR 一样，观测到 +1.67 p.p. 有多罕见？ 零假设 H₀：p_A = p_B pooled SE：把两组点击合并，估同一个共同 p
置信区间 真实提升大概落在哪个范围？ 不强行假设 p_A = p_B unpooled SE：A 用 A 的 p，B 用 B 的 p，分别估各自波动

用同一个例子看差别

在 Z 检验里，我们暂时站在零假设 H₀ 的世界：假设新旧样式真实点击率一样。既然“一样”，就应该把 A、B 两组数据合起来，估一个共同点击率 p_hat_pool。这就是 pooled 的含义：把信息合并起来估噪音。

p_hat_pool = (2000 + 2400) / (8000 + 9000) = 0.2588 SE_pool = √(0.2588 × 0.7412 × (1/8000 + 1/9000)) = 0.67%

但在置信区间里，我们不是在假设两组一样，而是在估计“B 到底比 A 高多少”。既然允许两组真实 CTR 不同，就不应该再强行合成同一个 p，而要让 A 用 A 的 p_hat_A，B 用 B 的 p_hat_B：

SE_unpooled = √(0.25×0.75/8000 + 0.2667×0.7333/9000) = 0.67%
?
为什么本例两个 SE 几乎一样？
因为 A 的 CTR 是 25.00%，B 的 CTR 是 26.67%，两者离得不远；样本量也都很大。所以无论用共同 p_hat_pool，还是分别用 p_hat_A、p_hat_B，估出来的噪音尺子都接近 0.67%。如果两组比例差得很远、样本量又小，两者差异会更明显。
!
记忆方式：检验 H₀ 时用 pooled，因为 H₀ 本身说“两组一样”；估计真实差异时用 unpooled，因为你不想把“可能不同”的两组硬合成一个 p。

第 5 章 · 公式

Z 分数：把差异翻译成"多少倍噪音"

目标：Z 是统计里的"信噪比"，有了它才能判断差异够不够大。

5.1 观测差异 vs 典型噪音

我们已经有两个数字：

观测差异 diff = p_hat_B − p_hat_A = +1.67 p.p. 典型噪音 SE_pool = 0.67 p.p.

直觉上：diff 是 SE 的多少倍，就代表这个差异有多"离谱"。这个倍数就叫 Z 分数：

Z = diff / SE_pool = 1.67% / 0.67% ≈ 2.48

翻译成人话：观测差异相当于 2.48 把噪音尺子。

5.2 为什么 Z 有意义

中心极限定理告诉我们：当样本量够大时，p_hat_B − p_hat_A 大致服从正态分布。在零假设下（两组一样），这个正态的均值是 0，标准差是 SE。所以 Z 把差异标准化到了 N(0, 1)：

在 H₀ 下： (p_hat_B − p_hat_A) / SE_pool ~ N(0, 1)

标准正态分布中：|Z| > 1.96 大约 5% 概率，|Z| > 2.58 只有 1%，|Z| > 3.29 只有 0.1%。所以 Z=2.48 说明"如果两组真的一样，看到这么大差异挺罕见的"。

第 6 章 · 公式

P 值：这个 Z 有多罕见

目标：把 Z 翻译成一个人人能读的概率数字。

6.1 P 值的定义

P
P 值 = 假如两组真的一样，看到当前这么极端（或更极端）差异的概率。

P 值小，说明"如果 H₀ 成立，出现当前结果太罕见了"，所以倾向于拒绝 H₀。更严谨地说：P 值小表示有统计证据支持两组存在差异，但它不直接证明“B 一定更好”，也不说明这个差异一定值得上线。

6.2 从 Z 到 P：正态曲线下的面积

Z 值在标准正态曲线上对应一个位置。"比它更极端"的部分，就是曲线两侧的尾巴面积。

双尾（默认）
P = 2·Φ(−|Z|)
不预设方向，同时看两侧尾部。A/B 实验默认双尾。
单尾
P = Φ(−Z)
只有在事先明确"就是要 B 更好"时才用，且必须提前声明。

本例 Z ≈ 2.48，查标准正态表或计算：

双尾 P = 2 × P(N(0,1) ≥ 2.48) ≈ 2 × 0.00657 ≈ 0.0131

结论：如果两组真实相同，出现 ≥ 1.67 p.p. 差异（正反方向都算）的概率只有 约 1.3%。一般以 0.05 为门槛，所以判定"差异显著"。

第 7 章 · 公式

置信区间：给差异划一个可能范围

目标：P 值告诉你"是不是显著"，置信区间告诉你"差异大概在多少之间"。

7.1 定义

95% 置信区间是一段由数据算出来的范围：如果反复做实验，并且每次都用同样方法构造区间，长期看大约 95% 的区间会包含真实差异。它由观测 diff 加减 1.96 倍 SE 得到：

95% CI = diff ± 1.96 × SE_unpooled = 1.67% ± 1.96 × 0.669% ≈ [ 0.36%, 2.98% ]

解读：本次数据给出的 95% 置信区间是 0.36 p.p. 到 2.98 p.p.。口语化可以说“我们有 95% 的信心认为真实提升落在这个范围附近”。因为区间整体大于 0，在这套近似下，正向差异有统计证据。

严格说，95% 描述的是这种造区间方法的长期覆盖率，不是“本次真实提升有 95% 概率落在已经算出的固定区间里”。

7.2 CI 与 P 值的对偶关系

i
当检验和区间使用同一套标准误、同一个近似分布时，95% CI 是否跨过 0，等价于双尾 P 值是否小于 0.05。这不是巧合，是同一件事的两种表述。本教程为了区分用途，Z 检验使用 pooled SE，置信区间使用 unpooled SE；本例两者非常接近，所以结论一致，但不要把这种等价理解成任何口径下都自动成立。

7.3 1.96 是哪来的

标准正态分布里，中间 95% 概率对应的边界正好是 ±1.96。想要 99% 置信区间，换成 ±2.576；想要 90%，换成 ±1.645。

7.4 动手看：置信度越高，区间越宽

置信度不是“越高越好”的免费午餐。你想更有把握覆盖真实差异，就必须给出更宽的区间。下面固定本例 diff = +1.67 p.p.、SE_unpooled = 0.669%，拖动置信度看区间如何变化。

第 7.5 章 · 设计

样本量、MDE、Power：实验开始前就要想清楚

目标：理解“不显著”不等于“没效果”，以及为什么要预先规划样本量和最小可检测提升。

前面几章都是在实验结束后解读结果。但真实 A/B 实验还有一个更早的问题：这次实验到底有没有能力看出你关心的提升？

7.5.1 三个词先分清

概念含义一句话记忆
显著性水平 α 如果真实没效果，你愿意承受多大概率误判“有效”。常用 0.05。 控制假阳性：别太容易误报。
Power（检验功效） 如果真实有你关心的效果，实验有多大概率能检出。常用 80% 或 90%。 控制漏报：真的有效时别太容易看不出来。
MDE Minimum Detectable Effect，最小可检测效果。例如“至少要能看出 +0.5 p.p.”。 先定义“多小的提升值得发现”。

7.5.2 为什么样本量决定你看不看得出来

Z 的分母是 SE，而 SE 会随着样本量变大而缩小。想检测更小的 diff，就要更小的 SE，也就是更多样本：

Z = diff / SE SE ∝ 1 / √n 想把可检测 diff 减半，样本量大约要变成 4 倍

这也是为什么第 8 章建议你把样本量乘 10 试一试：diff 不变时，样本越大，Z 越大，P 值越小。

7.5.3 一个最小样本量公式

如果两组样本量相同、基线 CTR 约为 p、你想检测的最小绝对提升是 δ（也就是 MDE），一个常用近似是：

每组样本量 n ≈ 2 · p(1−p) · (z_{1−α/2} + z_power)² / δ²

例如 baseline CTR = 25%，MDE = 1 p.p.，α = 0.05，Power = 80%：

z_{1−α/2} = 1.96，z_power ≈ 0.84 n ≈ 2 × 0.25 × 0.75 × (1.96 + 0.84)² / 0.01² ≈ 29,400 / 组

看到 P ≥ 0.05 时可能含义应该怎么说
真实确实没效果 B 和 A 差不多。 “没有发现足够证据证明 B 更好。”
真实有小效果，但样本不够 CI 很宽，既包含负向，也包含有价值的正向。 “当前实验信息不足，无法排除有价值的小提升。”
数据质量或实验前提有问题 SRM、埋点或分流异常。 “先不要解释 P 值，先修实验。”
i
实用规则：实验开始前写下三件事：主要指标是什么、MDE 是多少、计划样本量或运行时长是多少。实验结束后再改这些标准，会让 P 值解释变得不可信。

第 9 章 · 进阶

Z 检验和 t 检验：差别到底在哪里

目标：把前面学到的 Z 检验放到更大的统计检验框架里，理解什么时候该用 t 检验。

9.1 它们共同在做什么

Z 检验和 t 检验都在回答同一个问题：观测到的差异，相对于噪音来说有多大？

统计量 = 观测差异 / 标准误

所以它们的骨架完全一样：先定义零假设 H0，再算差异，再用 SE 把差异标准化，最后看这个标准化结果在某个参考分布下有多罕见。

i
你可以把 Z/t 都理解成信噪比。
分子是信号：观测到的均值差、比例差。分母是噪音：这个差异在随机抽样下本来会抖动多少。

9.2 Z 检验：噪音大小已知或大样本可近似

Z 检验用的是标准正态分布 N(0,1)。它适合两类场景：

  1. 总体标准差已知，例如数学题里直接告诉你 σ。
  2. 样本量足够大，虽然真实方差未知，但估计误差很小，可以用正态近似。

本教程的广告 CTR 属于第二类。点击/不点击是伯努利变量，点击总数严格服从二项分布，但样本量几千时，比例差可以用正态近似，所以使用比例 Z 检验。

单样本均值 Z = (x_bar − μ0) / (σ / √n) （σ 已知） 两比例差 Z = (p_hat_B − p_hat_A) / SE_pool （大样本近似）

这两个公式长得像，本质上都是“观测差异 / 噪音尺子”。区别在于：第一个比较一个样本均值和一个基准值；第二个比较两个比例。

公式符号含义适用场景
单样本均值 Z x_bar：样本均值
μ0：零假设下的基准均值
σ：已知的总体标准差
n：样本量
σ/√n：样本均值的标准误 		数学题或工业场景中总体标准差 σ 已知，想判断样本均值是否偏离某个基准。
两比例差 Z p_hat_A：A 组样本点击率
p_hat_B：B 组样本点击率
p_hat_B − p_hat_A：观测到的比例差
SE_pool：零假设下两组比例差的标准误 		CTR、CVR、留存率这类 0/1 指标，样本量足够大时用正态近似。

例 1：单样本均值 Z

假设某机器生产零件的标准长度是 μ0 = 10 mm，总体标准差已知 σ = 2 mm。你抽了 n = 100 个零件，样本均值 x_bar = 10.4 mm：

Z = (10.4 − 10) / (2 / √100) = 0.4 / 0.2 = 2

含义是：样本均值比基准高 0.4 mm，这个差异相当于 2 个标准误。

例 2：两比例差 Z

本教程的广告实验就是两比例差 Z。A 组点击率 25.00%，B 组点击率 26.67%，观测差异是 +1.67 p.p.；在“真实点击率相同”的零假设下，pooled SE 约为 0.67%。

Z = (p_hat_B − p_hat_A) / SE_pool = 1.67% / 0.67% ≈ 2.48

含义是：B 比 A 高出的这 1.67 p.p.，大约是零假设下随机噪音的 2.48 倍。

9.3 t 检验：噪音大小也要从样本估

t 检验最常见于连续型指标，比如人均停留时长、订单金额、GMV、人均播放次数。此时总体标准差 σ 通常不知道，只能用样本标准差 s 估计。

单样本均值 t = (x_bar − μ0) / (s / √n)
符号含义直觉
x_bar 样本均值 你从这批样本里算出来的平均值
μ0 零假设下的总体均值 你拿来比较的基准值，例如“旧版平均 30 秒”
s 样本标准差 这批样本本身有多分散，用来估计未知的总体标准差 σ
n 样本量 你收集了多少个观测值
s / √n 样本均值的标准误 样本均值 x_bar 这把尺子本身会抖动多少

所以这个公式可以按“信号 / 噪音”来读：

t = (样本均值 − 基准均值) / 样本均值的标准误

例如旧版页面平均停留时长是 μ0 = 30 秒。新版收集了 n = 100 个用户，样本均值 x_bar = 32 秒，样本标准差 s = 10 秒：

t = (32 − 30) / (10 / √100) = 2 / 1 = 2

含义是：新版平均停留时长比旧基准高 2 秒，这个差异相当于 2 个标准误。接下来再根据 t 分布和自由度 df = n − 1 判断它有多罕见。

注意这里分母里的 s 也是随机的。也就是说，t 检验不只要处理“均值有抽样波动”，还要处理“标准差本身也是估出来的”。这份额外不确定性让参考分布从正态分布变成了 t 分布。

t
t 分布比正态分布尾巴更厚。
样本量小时，s 不稳定，极端 t 值更容易出现，所以 t 分布会更保守。样本量变大后，t 分布会逐渐接近标准正态分布。

9.6 和本教程案例的关系

本教程里的 CTR 是比例指标，所以我们用 Z 检验。更精确地说，点击总数来自二项分布；当曝光量很大时，二项比例差近似正态，于是可以用 Z 检验。

如果指标换成人均停留时长，就不再是 0/1 比例，而是一组连续数字。此时你通常不知道总体标准差 σ，只能从样本算 s，于是应该使用 t 检验，常见版本是 Welch t 检验。

!
不要按“样本量大就永远用 Z”死记。
先看指标类型和建模假设：比例类指标常用 Z 或卡方近似；连续均值类指标常用 t；分布重尾或极端偏态时，还要考虑 bootstrap、delta method 或非参数方法。
小测验 9.1：CTR 这类 0/1 比例指标，在样本量足够大时通常用什么近似？
第 10 章 · 小结

你现在应该记住这些

核心链条

click/send → CTR (p_hat) 两组 CTR → diff = p_hat_B − p_hat_A p(1−p)/n → 单组 SE (单组噪音) 两组方差相加 → diff 的 SE diff / SE_pool → Z (检验 H₀ 的信噪比) Z → P 值 (罕见程度) diff ± 1.96·SE_unpooled → 95% 置信区间

词汇表

CTR
点击率 = 点击数 / 曝光数。
p.p.（百分点）
两个百分比相减的差，25% → 26.67% 相差 1.67 p.p.。
零假设 H₀
"两组真实 CTR 相同"这个默认假设。
SD 标准差
单次观测本身有多散。跟样本量 n 无关。
SE 标准误
用数据算出的统计量（如均值）有多不稳定。SE = SD / √n。
Z 分数
观测差异是多少个 SE。
P 值
假如 H₀ 成立，看到当前或更极端结果的概率。
置信区间
按同一方法重复实验时，约 95% 的区间会覆盖真实差异。
双尾 / 单尾
是否事先预设了方向。

常见陷阱

1
把 p.p. 和 % 搞混。"涨了 5%"和"涨了 5 个百分点"完全不一样。
2
把 P 值当作"B 更好的概率"。它是条件概率，条件是 H₀ 成立。
3
只看 P 值不看效应量。样本量极大时，0.001 p.p. 的差异也可能 P<0.05，业务上毫无意义。
4
反复"偷看" P 值。没跑完就多次看、达显著就停，会大幅提高假阳性率。要预先定好样本量和检验时点。
5
只看 CTR 不看后续。点击提升可能来自标题党、误触，要连带看下游转化、留存、投诉。

最终判断 checklist

问题通过后才能说什么
实验可信么？ 分流、SRM、埋点、实验单位没有明显异常，数据可以进入统计解释。
主指标显著么？ P 值和 CI 支持“随机波动不足以解释差异”。
效果够大么？ diff 或 CI 下界超过业务收益门槛，不只是统计上显著。
风险可接受么？ guardrail 指标没有明显伤害，或者收益足以覆盖风险。
流程干净么？ 没有偷看停实验、事后换指标、只汇报显著分群。
多指标处理对么？ 主指标、guardrail、探索指标在实验前分清；多个主指标预先做校正，不事后挑显著项。
中途查看合规么？ 如需中途看，提前设计 interim look 或 sequential / alpha-spending；否则只在最终时点决策。

下一步学什么

  • 连续型指标（GMV、时长）用 t 检验，SE 公式不同。
  • 同时看很多指标要做多重检验校正（Bonferroni / FDR）。
  • 实验开跑前用 power analysis 规划样本量。
  • 贝叶斯思路给出的是"B 比 A 好的概率"，与频率派 P 值本质不同。
