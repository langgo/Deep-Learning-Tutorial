CTR Prediction · Feature Interaction · FM + DNN

DeepFM

这篇论文的核心问题：在推荐和广告 CTR 预估中，既要记住低阶特征组合，也要自动发现高阶组合；DeepFM 用一个共享 embedding 的双塔结构，把 FM 和 DNN 端到端联合训练起来。

2 路FM 组件 + Deep 组件
共享同一份 raw input 与 embedding
无需FM 预训练与人工交叉特征
黑板版摘要
ŷ = sigmoid(yFM + yDNN)

yFM 学一阶和二阶交互：某个用户、某个广告、某个时间段本身是否重要，以及任意两个特征一起出现时的影响。

yDNN 学高阶交互：例如“男性 + 青少年 + 射击游戏 + 周末夜间”这类更复杂、非线性的组合。

最关键的设计不是“FM + DNN”本身，而是：两者共享同一份特征 embedding，低阶和高阶学习会共同塑造同一套表示。

1. CTR 预估到底在学什么？

目标

估计点击概率

训练数据由样本 (χ, y) 组成。χ 是一次曝光上下文，通常包含用户、物品、场景字段；y ∈ {0,1} 表示是否点击。模型输出 ŷ ∈ (0,1)，即预测 CTR。

推荐排序可直接按 CTR 排序；广告场景常用 CTR × bid 排序，因此 CTR 估计误差会直接影响收入。

难点

特征交互不是线性相加

论文举了两个直观例子：用户在饭点更可能下载外卖应用，这是“应用类别 × 时间”的二阶交互；男性青少年更喜欢射击或 RPG 游戏，这是“应用类别 × 性别 × 年龄”的三阶交互。

很多交互无法靠专家枚举。字段多、稀疏、长尾时，人工交叉特征会漏掉大量有效模式。

!
论文的出发点：线性模型偏低阶且需要人工交叉；深度模型擅长高阶但容易忽视低阶；Wide & Deep 能两者兼顾，但 wide 部分依赖人工特征工程。DeepFM 试图把这三类问题一起解决。

2. 先掌握 FM：用向量内积建模二阶交互

Factorization Machine 对稀疏场景特别有效。先统一记号：x∈R^d 是所有 field 拼接后的稀疏特征向量，i,j∈{1,...,d} 都是 feature 维度编号；w_i∈R 是第 i 个 feature 的一阶权重，V_i∈R^k 是第 i 个 feature 的 latent vector / embedding。FM 不为每一对特征单独学习交叉权重，而是用 <V_i,V_j> 表示两者交互强度。

yFM = Σi=1..d wixi + Σi=1..dΣj=i+1..d <Vi, Vj> · xi · xj

一阶项 Σ w_i x_i

表示单个 feature 本身的影响，例如“这个 app 类别整体 CTR 高”“这个城市点击率低”。整体参数 w 的 shape 是 [d]。

二阶项 <V_i,V_j>

表示两个 feature 共同出现的影响，例如“饭点 × 外卖”。整体 embedding 表 V 的 shape 是 [d,k]，单个 V_i 的 shape 是 [k]。

为什么适合稀疏数据

即使某一对特征很少共同出现，只要单个特征在其他样本中出现过，它们的 embedding 就能被更新，交互权重可泛化。

3. DeepFM 架构：共享 embedding 的 FM + DNN

下面按论文 Figure 1-4 的逻辑重画：DeepFM 不是简单把两个模型投票平均，而是让 FM 分支与 DNN 分支共用同一份输入特征和同一张 embedding 表 V∈R^{d×k}，最后在 logit 层相加。

图 1：DeepFM 分层数据流。记号说明：i∈{1,...,d} 是拼接后稀疏向量中的 feature 维度编号；w_i∈R 是 FM 一阶参数；V_i∈R^k 是 FM 的 latent vector，同时作为 DNN embedding lookup 的公共输入，整体 V∈R^{d×k}。DNN 自身参数是各层 W,b。红色是 FM 低阶交互，蓝色是 DNN 高阶交互，绿色强调共享的是 V / embedding。

论文里这一层有两个细节

  1. 不同 field 原始长度不同，embedding 长度相同。 例如 user_id 可能有十亿维，gender 只有几维，但每个被激活的 feature 都查表得到一个 k 维 V_i。
  2. FM 的 latent vectors 复用为 DNN 的 embedding 输入。 整体是同一张表 V∈R^{d×k}：FM 用它做二阶内积，DNN 从它查出 e_t 作为输入；DNN 额外还有自己的 MLP 参数 W,b。

3.2 三个 logit 分量分别代表什么？

一阶记忆

Σi=1..dwixi

单个 feature 本身的贡献。例：某 app 类别普遍点击率高。

二阶组合

Σi=1..dΣj=i+1..d<Vi,Vj>xixj

任意两个被激活 feature 一起出现的贡献。例：外卖 × 饭点。

高阶非线性

MLP([e1,...,em])

多字段、多层非线性组合。例：男性 × 青少年 × 射击游戏 × 周末夜间。

3.3 一次 forward pass 的计算顺序

稀疏输入。 每条曝光样本被编码成 x=[x_field1,...,x_fieldm]；拼接后总维度是 d，类别 field 通常只有一个非零 feature。
查表得到共享 embedding。 对每个 field 中被激活的 feature 编号 i 取出 V_i∈R^k，形成 field embedding e_t；这里 t∈{1,...,m} 是 field 编号。
FM 分支。 用 w_i∈R 计算一阶项，用共享 V_i∈R^k 的内积计算二阶项，得到标量 logit y_FM。
DNN 分支。 拼接 [e_1,...,e_m] 得到 a(0)∈R^{m×k}，进入 MLP 前通常 flatten 为 R^{mk}，经过多层 Linear + activation 得到 y_DNN。
联合输出与训练。 sigmoid(y_FM + y_DNN) 得到点击概率，用 LogLoss 反向传播；梯度更新 FM 一阶参数 w∈R^d、公共 embedding 表 V∈R^{d×k}、以及 DNN 自身参数 W,b。

3.4 参数、张量形状与训练目标

对象形状 / 含义在哪个分支使用
xx∈R^d，由 m 个 field 拼接得到；i∈{1,...,d} 是 feature 维度编号FM 与 embedding lookup
w_i / ww_i∈R；整体 w∈R^d，表示第 i 个 feature 的一阶标量权重仅 FM 一阶项使用
V_i / VV_i∈R^k；整体 V∈R^{d×k}，表示第 i 个 feature 的 latent vector / embeddingFM 二阶项使用；DNN 把查出的 V_i 当 embedding 输入
e_te_t∈R^k，第 t 个 field 里被激活 feature 查到的 embedding；t∈{1,...,m}DNN embedding 层
a(0)[e_1,e_2,...,e_m]，可看作 R^{m×k}，输入 MLP 前 flatten 为 R^{mk}DNN 输入层
W(l), b(l)若第 l 层输入维度为 h_l、输出维度为 h_{l+1}，则 W(l)∈R^{h_{l+1}×h_l}，b(l)∈R^{h_{l+1}}DNN 隐藏层
y_FM,y_DNN,ŷ单样本都是标量；batch 实现中通常是 [B,1]输出 logit / CTR

FM 二阶项的工程计算

直接枚举所有 pair 是 O(d²k)。实际实现常用等价变换把复杂度降到 O(dk)：

0.5 · Σf=1..k [(Σi vi,fxi)² - Σi(vi,fxi)²]

这也是教程伪代码里 (sum v)^2 - sum(v^2) 的来源。

训练目标

论文用 CTR 二分类目标，评价用 LogLoss。单样本损失可写成：

L = - y log(ŷ) - (1-y) log(1-ŷ)

反向传播不是只更新 DNN；FM 的 w、共享 embedding V、DNN 的 W,b 都一起更新。

4. DeepFM 与 FNN、PNN、Wide & Deep 的差异

模型核心做法论文指出的短板DeepFM 的对应改进
LR / FTRL线性加权不能自动学习交互；交叉特征需人工构造FM 分支自动学习二阶，DNN 分支学习高阶
FM一阶 + 二阶隐向量内积实际常只用到二阶，高阶复杂度高保留 FM 的低阶能力，并用 DNN 建模高阶
FNN先训练 FM，再用 FM embedding 初始化 DNN需要预训练；主要捕获高阶；embedding 容易被 FM 阶段限制无需预训练，端到端联合训练
PNNembedding 后加入 product layer计算复杂；低阶交互不足；外积近似可能丢信息FM 的 product 只连最终输出，结构更轻
Wide & Deepwide 记忆低阶/手工交叉，deep 泛化高阶wide 输入依赖专家特征工程，且与 deep 输入不同共享输入与 embedding，不需要额外人工交叉

5. 实验怎么证明有效？

数据集

  • Criteo：4500 万点击记录，13 个连续特征，26 个类别特征；90% 训练，10% 测试。
  • Company*：某应用商店游戏中心 7 天训练 + 下一天测试，约 10 亿记录；含 app、user、context 特征。

指标

  • AUC：排序质量，越高越好。
  • LogLoss：概率校准误差，越低越好。
  • 论文也比较训练时间：DeepFM 接近最有效率的深度 CTR 模型。

6. 超参数研究给工程实践的提示

ReLU 通常优于 tanh

论文在 Company* 数据上比较 relu 和 tanh，除 IPNN 外，relu 对深度 CTR 模型更合适。作者推测可能因为 relu 会诱导稀疏性。

合理 dropout 提升鲁棒性

论文测试保留概率 1.0 到 0.5。多数模型在 0.6 到 0.9 之间达到较好性能；过强或过弱正则都不稳。

更宽不一定更好

隐藏层神经元从 400 增到 800 不总是提升，OPNN 甚至变差。原因是模型复杂度上升后更容易过拟合。论文数据中 200 或 400 每层较合适。

更深也不一定更好

隐藏层数量先增加会提升效果，但继续增加后性能下降，仍然是过拟合和优化难度带来的代价。

constant shape 表现更好

在总神经元数固定时，论文比较 constant、increasing、decreasing、diamond 四种形状；constant，如 200-200-200，经验表现最好。

7. 如何从零实现一个 DeepFM？

训练流程

  1. 把每个样本拆成多个 field：用户、物品、上下文。
  2. 类别特征做 ID 化或 one-hot；连续特征可直接输入或离散化。
  3. 为每个稀疏 feature i∈{1,...,d} 学习一阶权重 w_i∈R 与 embedding V_i∈R^k。
  4. FM 分支计算一阶与二阶项。
  5. DNN 分支拼接 m 个 field embedding，得到 a(0)∈R^{m×k}，flatten 后过多层 MLP。
  6. 把两路 logit 相加，经 sigmoid 得到 CTR。
  7. 用 LogLoss / Binary Cross Entropy 端到端训练。

实现时容易犯错

  • 把 FM 和 DNN 做成两套 embedding，失去论文核心设计。
  • 连续特征未归一化，DNN 分支训练不稳。
  • 只看 AUC，不看 LogLoss，导致概率不准。
  • 离线 AUC 小幅提升不代表线上一定提升，还要做在线实验。
# PyTorch 风格伪代码：突出结构，不绑定具体数据管道
# 记号对应：feature_size=d, field_size=m, embed_dim=k, batch_size=B
class DeepFM(nn.Module):
    def __init__(self, feature_size, field_size, embed_dim, mlp_dims):
        super().__init__()
        self.linear = nn.Embedding(feature_size, 1)          # w table: [d, 1]
        self.embedding = nn.Embedding(feature_size, embed_dim) # V table: [d, k]，FM 与 DNN 共享
        layers = []
        in_dim = field_size * embed_dim
        for dim in mlp_dims:
            layers += [nn.Linear(in_dim, dim), nn.ReLU(), nn.Dropout(0.2)]
            in_dim = dim
        layers += [nn.Linear(in_dim, 1)]
        self.mlp = nn.Sequential(*layers)

    def forward(self, feat_ids, feat_values):
        # feat_ids: [B, m]，每个元素是 feature id i∈{1,...,d}
        # feat_values: [B, m]，连续特征取实际值，类别特征通常为 1
        values = feat_values.unsqueeze(-1)        # [B, m, 1]
        emb = self.embedding(feat_ids) * values   # [B, m, k]，即每个 field 的 e_t

        # FM 一阶
        linear_logit = (self.linear(feat_ids) * values).sum(dim=1)  # [B, 1]

        # FM 二阶：0.5 * ((sum e_t)^2 - sum(e_t^2))，等价于激活 feature 两两内积之和
        sum_square = emb.sum(dim=1).pow(2)        # [B, k]
        square_sum = emb.pow(2).sum(dim=1)        # [B, k]
        fm_logit = linear_logit + 0.5 * (sum_square - square_sum).sum(dim=1, keepdim=True)  # [B, 1]

        # DNN 高阶
        dnn_input = emb.flatten(start_dim=1)      # [B, m*k]
        dnn_logit = self.mlp(dnn_input)           # [B, 1]
        return torch.sigmoid(fm_logit + dnn_logit) # [B, 1]

9. 复盘：这篇论文该怎么记？

一句话

DeepFM = FM 的低阶交互记忆能力 + DNN 的高阶组合泛化能力 + 共享 embedding 的端到端训练。

最大贡献

相比 Wide & Deep，DeepFM 不需要给 wide 部分手工做交叉特征；相比 FNN，不需要 FM 预训练；相比 PNN，更轻且保留低阶。

局限与后续视角

论文没有解决所有高阶交互选择问题。作者也提到未来可引入 pooling 等策略，增强对最有用高阶交互的学习；后续 DIN、DCN、xDeepFM 等工作继续沿着“显式/隐式交互建模”发展。
