1一个 token 长什么样

一个 token 进入 attention 时,是一个长度 D 的向量(注意:这里 D 是一个头内部的宽度 head_dim,不是模型总宽度 n_embd)。

这个向量的每一个数,叫一个通道(channel)。D = 8 时,一个 token 在一个头里就有 8 个通道:

RoPE 的第一步:把相邻两个通道配成一对——D = 8 就配成 4 对。每对 (x₀, x₁) 看成一个二维平面上的向量(箭头):

要点:现在"一个 token 的向量"变成了"D/2 个 2D 箭头"。RoPE 要做的就是——把每个箭头旋转一个角度。关键是:转多少度?

2关键:位置 t 决定旋转角度

你问得非常好:"T=0 和 T=1 应该有相对位置关系,但旋转是发生在通道上,怎么反应到 T 上?"

答案是:每一个位置的 token,都是一个独立的向量。位置 0 的 token、位置 1 的 token、位置 2 的 token……它们是 T 个独立的向量。RoPE 对它们的处理是:

位置 t = 0: 旋转 0 度 ← 不转 位置 t = 1: 旋转 θ 度 ← 转一点 位置 t = 2: 旋转 2θ 度 ← 转两倍 位置 t = 3: 旋转 3θ 度 位置 t = 4: 旋转 4θ 度 ... 位置 t : 旋转 t·θ 度 ← 和位置成正比

θ 来自哪? θ 是和"通道对编号"有关的频率。本面板先固定看第 0 对通道(高频),你拖动滑块设定序列长度 T:

怎么看:上面是 T 个位置的 token——假设它们的向量内容完全相同(便于隔离位置效应)。但经过 RoPE 后,每个位置的箭头指向都不一样——因为位置不同、旋转角度不同。
• 位置 0 的箭头指向正右方(没转);
• 位置 1 的箭头转了 θ = freq[c] 弧度;
• 位置 t 的箭头转了 t × freq[c] 弧度。
核心:"位置信息"没有被加到 token 里,而是用"转了多少度"来表示。
位置 0 和位置 1 之间"相差了多少位置",就表现为它们的箭头"相差了多少度"——这就是位置关系在通道上的表达。
位置 2 和位置 1 相差 1 个位置、箭头相差 θ 度;位置 5 和位置 3 相差 2 个位置、箭头相差 2θ 度……相对位置差 = 箭头角度差。

3多尺度:不同通道对转速不同

第 2 步固定看了"第 0 对通道"。但一个 token 有 D/2 对通道,RoPE 让每对的转速(频率)都不同——这是它比朴素位置编码聪明的地方:

通道对 0 : freq[0] = 1 ← 最快,相邻位置差 1 弧度 通道对 1 : freq[1] = 1 / 100000^(2/D) ← 稍慢 通道对 2 : freq[2] = 1 / 100000^(4/D) ... 通道对 D/2-1: freq[D/2-1] ≈ 1/100000 ← 最慢,相邻位置几乎看不出差别

固定一个位置 t,看它所有 D/2 对通道各被转了多少角度:

怎么看:每个小时钟是一对通道。从左到右:高频→低频。拖动位置 t:
• 左边高频对:位置稍微动一下指针就飞转——编码细粒度位置(第几个 token 立即可辨);
• 右边低频对:位置变化几十上百指针才动一点——编码粗略范围(第几百个 token、第几千个 token)。
所以 RoPE 像一组粗细不同的尺子,同时测量位置的多个尺度。
为什么要多尺度? 单一频率会周期性重复(走一圈又回到原点)。多个不同频率组合后,在模型实际使用的有限上下文范围内更容易区分位置尺度;但这不是“数学上永不重复”或“无限长度都唯一”的保证。

4结果:Q·K 的分数为什么只依赖 i−j

attention 的核心是 Q·K(内积,点积)。RoPE 对位置 i 的 Q 转了 i·freq,对位置 j 的 K 转了 j·freq。于是:

内积的结果 ∝ cos(θ_i − θ_j) = cos((i − j) × freq) ↑ 只和相对位置 (i − j) 有关

怎么看:
• 蓝色虚线是 Q 的位置 i;
• 红色曲线是 K(j) 和 Q(i) 的内积,随 j 变化;
• 在这个“所有内容向量相同”的特例中,j=i 处达到最大值;离开后曲线会随多组正弦/余弦振荡,不保证单调衰减。
关键实验:拖动 i 滑块——同一个相对位移 i−j 对应同样的函数值。有限画布会裁掉曲线两端,所以视觉上不一定是完整曲线的简单平移。
收尾:
① 第 1 步建立了"向量 → D/2 对通道 → 2D 箭头"的分解;
② 第 2 步把位置 t 变成了旋转角度 t·freq——这就是位置信息的物理载体;
③ 第 3 步用多尺度频率在有限上下文内提供不同粒度的位置信号;
④ 第 4 步揭示:两个位置做 Q·K 时,旋转角之差 (i−j)·freq 自动进入内积——位置依赖只通过相对位移出现。
RoPE 提供相对位移信号,但不预设“越近权重越高”;最终注意力仍由内容和训练决定。
