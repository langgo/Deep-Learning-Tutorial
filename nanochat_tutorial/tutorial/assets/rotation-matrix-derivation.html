旋转矩阵的由来

配合 tutorial/04-gpt-attention.md §6 的 apply_rotary_emb。本页从极坐标出发,一步步推出 (x₁, x₂) → (y₁, y₂) 的旋转公式,并解释为什么 nanochat 源码里有一个"负号"。

阅读路径

  1. 向量的极坐标表示 —— (x₁, x₂) 可以写成 (r cos α, r sin α)
  2. 旋转就是改变角度 α —— 新角度 = 原角度 + θ
  3. 展开三角和差公式 —— 得到标准的旋转矩阵
  4. nanochat 用的是 -θ —— 为什么有个负号
  5. 交互:同时验证公式和图

1向量的极坐标表示

任何一个 2D 向量 (x₁, x₂),都可以用两个数来等价描述:

  • 长度 r = √(x₁² + x₂²)
  • 角度 α —— 和 x₁ 轴的夹角

所以:

x₁ = r · cos α x₂ = r · sin α

拖动滑块看一个具体向量:

要点:向量不只是 (x₁, x₂) 这一个表示——它也可以是 (r, α)。 这个"换个视角"是推导旋转矩阵的关键。

2旋转就是改变角度 α

既然向量可以用 (r, α) 描述,那么旋转一个角度 θ 就非常简单:

旋转前: (r, α) 旋转后: (r, α + θ) ← 长度不变、角度加 θ

翻译回直角坐标:

y₁ = r · cos(α + θ) y₂ = r · sin(α + θ)

拖动看:

蓝色箭头是原向量,橙色是旋转后。弧线显示从 α 转到 α+θ 的角度变化。
核心:到这里已经讲完了"旋转"本身。接下来三步只是把公式整理成只用 (x₁, x₂) 的形式——不再出现 α 这个中间量。

3展开三角和差公式

第 2 步得到:

y₁ = r · cos(α + θ) y₂ = r · sin(α + θ)

用高中三角和差公式展开:

cos(α + θ) = cos α · cos θ − sin α · sin θ sin(α + θ) = sin α · cos θ + cos α · sin θ

两边各乘 r:

y₁ = (r cos α) · cos θ − (r sin α) · sin θ y₂ = (r sin α) · cos θ + (r cos α) · sin θ

看圆括号里的两个表达式——它们正是 x₁ 和 x₂ 的极坐标形式!代入:

由第 1 步:x₁ = r cos α, x₂ = r sin α
代入上面得:y₁ = x₁ · cos θ − x₂ · sin θ
y₂ = x₂ · cos θ + x₁ · sin θ

整理成矩阵形式:

[ y₁ ] [ cos θ -sin θ ] [ x₁ ] [ ] = [ ] · [ ] [ y₂ ] [ sin θ cos θ ] [ x₂ ]
这就是标准的"逆时针旋转 θ 度"矩阵。任何线性代数教科书、任何图形学课程都用这个版本。
注意符号:右上角是 -sin θ,左下角是 +sin θ。

4nanochat 用的是 -θ:为什么有个负号

看 nanochat 的源码(nanochat/gpt.py:57):

def apply_rotary_emb(x, cos, sin): # note: this rotates by -theta, the transpose of the textbook convention. # Functionally equivalent (only the relative q/k rotation matters), # kept for checkpoint compatibility. ... y1 = x1 * cos + x2 * sin y2 = x1 * (-sin) + x2 * cos

展开成矩阵:

[ y₁ ] [ cos θ sin θ ] [ x₁ ] [ ] = [ ] · [ ] [ y₂ ] [ -sin θ cos θ ] [ x₂ ]

和第 3 步的标准矩阵对比——sin θ 的两个符号刚好反了。这等价于把标准矩阵里的 θ 替换成 -θ:

cos(-θ) = cos θ ← 不变 sin(-θ) = -sin θ ← 变号 所以 "逆时针转 -θ" = "顺时针转 θ" = "标准矩阵的转置"

这就是源码注释说的 "rotates by -θ, the transpose of the textbook convention"。

为什么源码要这样写? 答案就一句话:checkpoint 兼容性——改了符号以后,已经训好的模型权重就对不上了。
从 RoPE 的核心性质("Q·K 只依赖 i−j")来说,顺时针逆时针完全等价:只要 Q 和 K 都用同一个方向,相对关系就对。所以 nanochat 不改。
