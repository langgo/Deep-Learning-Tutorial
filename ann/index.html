ANN 近似最近邻检索算法总览

Approximate Nearest Neighbor Search — 工程实践中主流算法从原理到实现的可视化教程

为什么需要 ANN？

在推荐系统、向量搜索、图像检索、语义搜索、RAG（检索增强生成）等场景中，我们经常需要在 百万甚至十亿级向量 中查找与查询向量最相似的 top-K。精确最近邻（Exact k-NN）在高维数据上 时间复杂度接近 O(N)，无法满足生产级的延迟和吞吐要求。

ANN（Approximate Nearest Neighbor）通过牺牲少量精度（通常召回率 90-99%）换取几个数量级的性能提升， 是现代向量搜索的基石技术。本教程覆盖 5 大类 16 种 工程常用算法， 从直观理解、算法原理、交互式演示到工程选型对比。

推荐学习路径

工程实践角度的最佳学习顺序（由易到难，每一步都为下一步铺垫）：

KD-Tree → Ball Tree → Annoy → Classic LSH → MinHash → SimHash
SQ → PQ → IVF-PQ → OPQ → HNSW ★ → NSG
DiskANN → SPANN → IVF-HNSW → ScaNN

量化章节把 IVF-PQ 提前到 OPQ 之前 是有意为之：读者应该先理解 "工程系统怎么落地"（IVF-PQ 是 Faiss 主力方案）， 再学 OPQ 的 "锦上添花"（正交旋转优化）。图算法从 HNSW 起步（生态主流），依次深入 NSG（省内存）→ DiskANN（磁盘）→ SPANN（更极致）。

关键术语速查（初学者建议先展开浏览一遍）
向量 / embedding
用一组数字表示的对象（图像、文本、用户），维度 D 通常是 64-1024。
最近邻 K-NN
在 N 个向量里找距离查询向量最近的 K 个。
近似 ANN
不保证找到真正最近的 K 个，但用极小误差换千倍速度。
召回率 Recall@K
返回的 K 个里有多少个是真近邻，越接近 100% 越好。
QPS
每秒查询数（Queries Per Second）。
K-Means 聚类
把 N 个点分成 k 组，每组用组中心代表，反复迭代到收敛。
Voronoi 单元
每个中心的"势力范围"——空间中所有离它最近的点组成的区域。
余弦 / 内积 / L2
三种常见的距离度量。归一化后余弦与内积等价，也可转 L2。
维度诅咒
维度越高，任意两点的距离越趋近相等 → 剪枝失效 → 树结构退化为暴力扫。
倒排索引 IVF
先粗聚类分桶，查询时只扫少数几个桶（nprobe 个），跳过大量数据。
码本 codebook
量化用的 k 个中心的集合。每个数据点在码本里存"码字 codeword"（索引）。
LUT 查找表
预计算 M 段 × k 个的距离表，查询时用 M 次查表+加法算近似距离。
邻近图 proximity graph
每个向量做节点，与近邻建边，查询时贪心/beam search 跳转。
MIPS
Maximum Inner Product Search，最大内积搜索，推荐系统主流场景。
1

基于树的方法 Tree-based

通过递归划分空间构建树结构，查询时沿树下降 + 回溯剪枝。经典而直观，低维（<20）效果好， 高维退化明显。工业界常见于静态/只读服务。
KD-Tree
K-Dimensional Tree
最经典的空间划分树，轴对齐分割。低维近似最优，高维维度诅咒。
Ball Tree / VP-Tree
Ball Tree / Vantage Point Tree
以质心 + 半径划分嵌套球，支持任意度量，中等维度优于 KD-Tree。
Annoy ★ Spotify
Approximate Nearest Neighbors Oh Yeah
随机投影树森林，支持 mmap，构建后只读，静态服务经典选择。
2

基于哈希的方法 Locality Sensitive Hashing

设计"局部敏感"的哈希族——相似向量以高概率碰撞、不相似的以低概率碰撞。内存占用小， 理论保证明确，适合超大规模和流式数据。
经典 LSH
Random Projection / p-stable LSH
欧氏/余弦距离的随机超平面投影哈希，AND-OR 组合放大间隙。
MinHash
Min-wise Hashing
Jaccard 相似度估计的黄金方法，用于文本/集合去重、聚类。
SimHash ★ Google
Similarity Hashing
Google 网页去重，加权符号哈希 → 汉明距离比较。
3

基于量化的方法 Quantization

把高维浮点向量压缩为紧凑的编码（几字节），用查找表快速估算距离。内存压缩极高（16-64x）， 是十亿级向量索引的必选武器。Faiss 的核心方案。
PQ ★★
Product Quantization
向量切段独立聚类，LUT 查表加速。Jégou 2011 经典论文。
OPQ
Optimized PQ
PQ 前学习一个旋转矩阵，降低量化误差，通常提升 5-15% 召回。
IVF-PQ / IVFADC ★★★
Inverted File + Product Quantization
Faiss 的主力方案：IVF 粗聚类倒排 + PQ 精排。十亿级向量首选。
SQ
Scalar Quantization
最简单的量化：float32 → int8/int4，4-8x 压缩几乎无损。
4

基于图的方法 Graph-based

每个向量作为节点，与近邻节点建边形成邻近图；查询时从入口点开始贪心/beam 搜索。 当前召回-延迟最好的方案之一，Milvus、Qdrant、Weaviate、pgvector、Elasticsearch(Lucene)、Vespa 等主流向量数据库均以 HNSW 为主力索引。
HNSW ★★★★
Hierarchical Navigable Small World
多层跳表式邻近图，Malkov 2016 (arXiv) / TPAMI 2018，向量数据库事实标准。
NSG / NSSG
Navigating Spreading-out Graph
单层图，MRNG 选边规则去除冗余边，Fu et al. VLDB 2019，内存比 HNSW 更省。
DiskANN / Vamana ★ 微软
Disk-Resident ANN
图存 SSD，alpha 剪枝生成"长跳边"，单机十亿级低成本部署。
SPANN ★ 微软
Space Partition tree + Neighborhood Graph
内存粗聚类 head + 磁盘 posting list，NeurIPS 2021。
5

混合方案 Hybrid

组合以上多种范式，扬长避短。例如用 HNSW 加速 IVF 中心查找、用 PQ 压缩图节点向量存储。 工业界大规模生产系统的最终形态。
IVF-HNSW / HNSW-PQ
IVF + HNSW + PQ Composite
HNSW 加速 IVF 中心查找 + PQ 压缩存储，兼顾内存与速度。
ScaNN ★ Google
Scalable Nearest Neighbors
各向异性量化 + 树/图剪枝，ICML 2020，GloVe/SIFT benchmark 领先。
